Welcome to **ChessLens**, the ultimate post-game analysis tool for the true chess-o-holic. Whether you're hanging queens in time trouble, grinding the endgame like Magnus, or trying to figure out why your "brilliant sacrifice" was actually a +M3 blunder, ChessLens has you covered. 

Built with the blazing speed of **TanStack Start + Vite**, this modern TypeScript application connects directly to your favorite arenas (Lichess and Chess.com), pulls your PGNs, and runs them through the digital wringer to help you gain that sweet, sweet Elo.

---

## ♛ The Repertoire (Features)

*   **The Opening Setup:** Seamlessly fetch games from both **Chess.com** and **Lichess.org** using just a username. No manual PGN copying required!
*   **Tactical Vision:** Deep web-based analysis to evaluate your moves. We'll highlight your *Brilliant (!)* moves, forgive your *Inaccuracies (?)*, and ruthlessly point out your *Blunders (??)*.
*   **Time-Scramble Analytics:** See how you perform under pressure in Bullet, Blitz, and Rapid time controls.
*   **Opening Book Explorer:** Identify which variations of the Sicilian are winning you rating points, and which ones are sending you back to the lobby.
*   **Ultra-Fast UI:** Powered by TanStack Start and Vite for near-instant routing and blazing-fast performance.

## ♟️ Setting up the Board (Installation)

Don't let the setup clock flag you. Getting ChessLens running locally is easier than a Scholar's Mate.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/sriramsai18/ChessLens.git](https://github.com/sriramsai18/ChessLens.git)
   cd ChessLens
2. **Install dependencies:**
   We recommend using Bun for lightning-fast installs, but npm works perfectly fine too!
   bun install
   or npm install
3. **Start the development server:**
   bun run dev
   or npm run dev
